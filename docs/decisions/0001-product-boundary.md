# 0001: WT Builder product boundary

Status: accepted

## Decision

Create WT Builder as a new, public repository and a single-purpose product for
assembling one Weekly Thing issue at a time.

Studio remains operational evidence and a source of selectively reusable code.
WT Builder does not inherit Studio's product framing or interaction model.

## Consequences

- Product discovery can proceed without destabilizing the live pipeline.
- The first milestone is a validated prototype, not production parity.
- Integration code will be selected after the interface and item contracts are
  proven.
