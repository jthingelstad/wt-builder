# Prototype workspace

Claude Design should place the interactive prototype here.

The prototype may use any lightweight local frontend stack appropriate for
rapid iteration, but it must remain:

- local and non-publishing,
- driven by `fixtures/representative-issue.json`,
- easy for Jamie to launch,
- accessible without drag-and-drop,
- explicit about simulated integrations, and
- disposable if the interaction model does not validate.

Do not add production infrastructure during this phase.
